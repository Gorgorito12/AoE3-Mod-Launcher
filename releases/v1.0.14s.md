# AoE3 Mod Launcher v1.0.14s

> **[⬇ Download Aoe3ModLauncher.exe](https://github.com/Gorgorito12/AoE3-Mod-Launcher/releases/tag/v1.0.14s)**
> — the launcher updates itself when you open it. This link is for when that cannot work.
>
> **La versión en español está más abajo.** · *The Spanish version is further down.*

## Wars of Liberty
- **New installs get WoL 1.2.0e directly**, no patch chain to run afterwards.
- **Fixed: a fresh install could show the game in your AoE3's language and with vanilla
  data.** Ten leftover base-game files are now removed, as the official patches do. An install
  made before this update is not fixed by Repair — reinstall, or ask on Discord.
- **Patches now remove whole folders when they are told to** (e.g. old *War of the Triple
  Alliance* art), so your install matches everyone else's.

## Local files & uninstalling
- **The LOCAL FILES tab, the uninstall window and the antivirus dialog were redesigned.**
- **You can uninstall any copy of a mod, not only the active one**, from LOCAL FILES. Your other
  copies are not touched.
- **Safer uninstall:** the launcher refuses to uninstall a folder that contains your Age of
  Empires III itself.
- **The antivirus dialog** shows the two folders to exclude, copies both in one click, and has a
  button that opens Windows Security.

## Multiplayer
- "How ranks work" is now a proper button on the Ranking.

# AoE3 Mod Launcher v1.0.14s (Español)

> **[⬇ Descargar Aoe3ModLauncher.exe](https://github.com/Gorgorito12/AoE3-Mod-Launcher/releases/tag/v1.0.14s)**
> — el launcher se actualiza solo al abrirlo. Este enlace es por si eso falla.

## Wars of Liberty
- **Las instalaciones nuevas reciben directamente WoL 1.2.0e**, sin cadena de parches después.
- **Arreglado: una instalación nueva podía mostrar el juego en el idioma de tu AoE3 y con datos
  del juego base.** Ahora se quitan diez archivos sobrantes del juego base, como hacen los parches
  oficiales. Una instalación hecha antes de esta versión no se arregla con Reparar: reinstala, o
  pregunta en Discord.
- **Los parches ahora borran carpetas completas cuando lo indican** (p. ej. el arte viejo de
  *War of the Triple Alliance*), así tu instalación queda igual que la de los demás.

## Archivos locales y desinstalar
- **Se rediseñaron la pestaña ARCHIVOS LOCALES, la ventana de desinstalar y el aviso del
  antivirus.**
- **Puedes desinstalar cualquier copia de un mod, no solo la activa**, desde ARCHIVOS LOCALES.
  Tus otras copias no se tocan.
- **Desinstalar es más seguro:** el launcher se niega a desinstalar una carpeta que contenga tu
  propio Age of Empires III.
- **El aviso del antivirus** muestra las dos carpetas a excluir, copia ambas con un clic y tiene
  un botón que abre Seguridad de Windows.

## Multijugador
- «Cómo funcionan los rangos» ahora es un botón de verdad en la Clasificación.
